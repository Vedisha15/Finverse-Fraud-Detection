# Data

Finverse uses the BankSim transaction dataset.

Expected file:

```text
bs140513_032310.csv
```

The original notebook loads the dataset from:

```text
/kaggle/input/banksim1/bs140513_032310.csv
```

For GitHub, keep the raw CSV outside the repository because it can be large and may have separate dataset licensing/usage terms.

Place the CSV locally in this folder when running your own copy of the project.

# Models

## Machine Learning Model

Finverse: Instant Fraud Alerts uses an XGBoost Classifier for fraud detection.

The model classifies transactions into:

- Genuine transactions
- Fraudulent transactions

### Model Used

**XGBoost Classifier**

### Model Evaluation

The project uses Area Under the Precision-Recall Curve (AUPRC) as the main evaluation metric because the dataset is highly imbalanced.

| Model Setup | AUPRC |
|---|---:|
| Standard Features | 0.8331 |
| Feature-Engineered Features | 0.8812 |

### Saved Model

The notebook saves the trained model as:

`XGB-BankSim.pkl`

The trained model file is not included in this repository by default.

The model can be regenerated by running the notebook.

# Data

## Dataset

Finverse: Instant Fraud Alerts uses the BankSim transaction dataset for fraud detection analysis.

### Dataset File

The expected dataset file is:

`bs140513_032310.csv`

The original notebook loads the dataset from:

`/kaggle/input/banksim1/bs140513_032310.csv`

### Dataset Statistics

| Metric | Value |
|---|---:|
| Total Transactions | 594,643 |
| Fraud Transactions | 7,200 |
| Genuine Transactions | 587,443 |
| Fraud Rate | Approximately 1.21% |

### Important Note

The raw CSV dataset is not included in this repository.

The dataset should be downloaded separately and the file path should be updated according to the local environment.

The notebook uses the BankSim dataset for exploratory analysis, feature engineering and fraud detection model training.
